Lucky Engineering Business Management System

English-only professional web app demo.

Included modules:
- Customers
- Stock / Inventory
- Invoices with printable company invoice
- Accounts: income, expenses, profit
- Users / roles
- Dashboard
- Backup and restore

How to open:
1. Extract this ZIP file.
2. Open index.html in Chrome or Edge.
3. Add customers, stock items, invoices and transactions.

Important:
This package is an online-ready frontend demo that stores data in the browser using localStorage.
For a real public online website with secure login and shared database, connect it to Supabase/Firebase/MySQL and host it on Vercel, Netlify or cPanel hosting.
